# Brief

## What it is

GridFlow is a visual Instagram content planning platform. Plan and arrange your feed in a
true-to-life grid preview, so your profile always looks exactly the way you intend.

## Scope

**MVP:** a mockup and planning tool — arrange and preview a feed grid before posting
anywhere. **Stretch (post-MVP):** direct Instagram connection and scheduling; cron
infrastructure for scheduled posting is reserved for this stretch phase.
